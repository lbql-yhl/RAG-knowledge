# 办公设备与账号

## 新员工入职设备

新员工入职当日，IT 部门会发放：
- 笔记本电脑一台
- 显示器一台
- 门禁卡一张

## 软件安装

公司统一使用以下软件，可在内网软件中心自助安装：
- 企业微信
- 办公套件
- 开发工具（按岗位需要）

## 账号申请

### 邮箱
入职后系统自动开通企业邮箱，格式为 `姓名拼音@company.com`。

### VPN
远程办公需申请 VPN 账号，向 IT 部门提交申请，审批后 1 个工作日内开通。

## 设备报修

设备故障可通过 IT 服务台提交工单，响应时间：
- 紧急故障：2 小时内响应
- 一般故障：1 个工作日内响应
