# 文档上传与命名规范示例

## 一、适用范围

本规范适用于所有上传到知识库的 Markdown 文档。

## 二、文件命名

- 使用**中文或英文**命名，避免特殊符号
- 名称应能概括内容，例如 `报销流程.md`、`新员工入职手册.md`
- 同一目录下名称不可重复

## 三、内容格式

文档正文推荐包含以下结构：

1. 一级标题作为文档名
2. 用二级/三级标题划分章节
3. 关键信息使用**粗体**强调
4. 步骤类内容使用有序列表

## 四、目录组织

| 目录 | 用途 |
| --- | --- |
| `hr` | 人事制度与流程 |
| `it` | 网络、设备与安全 |
| `运维` | 服务器与发布 |
| `运营` | 业务流程与客户服务 |

## 五、上传示例

```text
# 费用报销流程

## 适用范围
全体员工因公产生的费用报销。

## 报销类别
- 差旅费
- 招待费
```

上传后系统会自动索引，即可通过 AI 问答检索到该文档内容。
