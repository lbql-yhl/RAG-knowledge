# 示例知识库文档

这里仅保留可公开发布的示例文档，方便首次启动和测试 Markdown 知识库功能。

> 真实项目中的内部资料、员工信息、网络安全配置和业务文档请放入本地 `docs/` 目录，但不要提交到公开仓库。

## 添加自己的文档

将 Markdown 文件放入 `docs/` 下后运行：

```powershell
python -m scripts.ingest
```

或者在网页中点击“重建索引”。

## 示例知识库目录

仓库已提供五个可公开发布的示例库：

- `docs/运维/`：故障响应、发布与回滚
- `docs/人工智能/`：RAG、提示词与引用规范
- `docs/开发/`：API、工程规范与可访问性
- `docs/运营/`：客服发货时效、售后和业务流程
- `docs/hr/`：报销、请假、入职与招聘流程
