# 项目立项流程示例

## 一、适用范围

本流程适用于公司内部所有新项目的立项申请，包括产品研发、市场活动与流程优化类项目。

## 二、立项前准备

发起立项前，请先确认以下几点：

- 项目目标是否明确、可量化
- 是否已有同类型项目在运行（避免重复投入）
- 预算与人力是否有初步估算

> 立项申请必须在项目启动前提交，先启动后补申请的原则上不予受理。

## 三、申请步骤

1. 填写《项目立项申请表》
2. 提交给直属负责人审批
3. 由 PMO 统一评审排期
4. 评审通过后进入项目启动会

## 四、需要提交的材料

| 材料 | 是否必需 | 说明 |
| --- | --- | --- |
| 立项申请表 | 是 | 含目标、范围、里程碑 |
| 预算明细 | 是 | 超过 5 万元需财务会签 |
| 资源需求清单 | 否 | 涉及跨部门时需填写 |

## 五、常见问题

**问：立项被驳回后能否再次提交？**
可以。根据驳回意见修订后重新提交，同一项目最多提交 3 次。
